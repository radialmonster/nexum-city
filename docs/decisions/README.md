# Architecture decision records

One short Markdown file per consequential, durable decision, named `NNNN-short-title.md`.

Each record covers:

- context;
- the decision;
- consequences and trade-offs;
- date and owner.

Numbering continues from the prototype. ADRs 0001–0029 belong to the prototype and are kept in its private archive repository. Where they conflict with records here, they are superseded. ADR 0028 (no privileged home district) still applies to the rewrite.
